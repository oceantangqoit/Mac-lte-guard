## Проблема

Многие USB-модемы LTE и USB-адаптеры Ethernet «зависают» после того, как Mac поспал с закрытой крышкой: индикатор горит, интерфейс в системе есть, а трафика нет. **Помогает только физическое переподключение.**

Причина: во сне macOS не снимает питание с USB (VBUS управляется прошивкой SMC, публичного API нет), а USB-сессия со стороны устройства уже мертва. Перезапуск сетевой службы не помогает — сбрасывать нужно уровень USB.

## Пришли из поиска?

Все эти формулировки описывают одно и то же:

> не работает USB Ethernet адаптер после сна Mac · MacBook теряет сеть после спящего режима · USB-C адаптер не просыпается · сетевой порт док-станции не определяется после сна · LTE модем отваливается после сна macOS

На форумах Apple и MacRumors годами накапливаются одинаковые сообщения — и на Intel, и на Apple Silicon. Обычные советы (сброс SMC/NVRAM) на Apple Silicon просто не существуют и причину не устраняют. **Надёжно работает только переподключение адаптера — именно это и автоматизирует данная утилита.**

## Решение

LTE Guard живёт в строке меню и слушает события пробуждения. После пробуждения он проверяет выбранный адаптер: если шлюз не отвечает, через IOKit выполняется **программное переподключение (USBDeviceReEnumerate)** — эквивалент физического рывка кабеля. Связь обычно возвращается **примерно за 8 секунд**.

- 🎯 **Не зависит от бренда** — VID/PID определяются при выборе, встроенного списка устройств нет
- 🔌 **Работает и с не-USB адаптерами** — автоматически переходит к перезапуску сетевой службы
- 🛠 **Команда после восстановления** — например, перезапустить прокси или переподключиться
- 🌍 **53 языка** — следует языку системы, переключается из меню
- 🪶 **Никаких зависимостей** — одно приложение, без демонов и Homebrew

## Установка

Скачайте `.dmg` из [Releases](../../releases) и перетащите в «Программы».

Если macOS сообщает, что разработчик не может быть проверен (норма для неподписанных приложений): **правый клик по приложению → Открыть → Открыть**, либо в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/LTEGuard.app
```

## Использование

1. В строке меню появится значок
2. Меню → **Выбрать адаптер…** → укажите свой адаптер (записи с `· USB` поддерживают программное переподключение)
3. Готово. Дальше после закрытия крышки всё чинится само

Если что-то не так, выберите в меню **Запустить диагностику**.
