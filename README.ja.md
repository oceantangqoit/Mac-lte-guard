## 問題

多くの USB LTE モデムや USB 有線 LAN アダプタは、Mac を閉じてスリープさせた後に「フリーズ」します。ランプは点いたまま、インターフェースもシステム上に存在するのに通信できず、**一度抜いて挿し直すまで復旧しません**。

原因は、スリープ中も macOS が USB 給電を切らない（VBUS は SMC ファームウェアが直接管理し、ソフトウェアからは制御できない）一方で、デバイス側の USB セッションが失われるためです。ネットワークサービスの再起動では直りません。リセットが必要なのは USB 層だからです。

## 検索から来た方へ

次のような症状はすべて同じ問題です:

> Mac スリープ後 有線LAN 使えない · USB LANアダプタ 復帰後 認識しない · スリープ復帰 ネットワーク 切断 · USB-C イーサネットアダプタ 動かない · ドック LANポート 認識しない · LTE モデム スリープ後 切断

Apple 公式コミュニティや MacRumors には、Intel 機・Apple Silicon 機を問わず何年にもわたって同じ報告が寄せられています。よく案内される SMC/NVRAM リセットは Apple Silicon には存在せず、根本的な解決になりません。**確実に効くのはアダプタの抜き差しだけ——本ツールはそれをソフトウェアで自動化します。**

## 仕組み

LTE Guard はメニューバーに常駐し、システムの復帰イベントを監視します。復帰後に対象アダプタを点検し、ゲートウェイに ping が通らなければ IOKit 経由で **ソフトウェア的な抜き差し（USBDeviceReEnumerate）** を実行します。物理的な抜き差しと同等で、**通常 8 秒ほどで復旧** します。

- 🎯 **メーカーを問わない** — 選択時に VID/PID を自動検出、内蔵デバイスリストなし
- 🔌 **USB 以外のアダプタにも対応** — ネットワークサービス再起動に自動フォールバック
- 🛠 **復旧後のコマンド実行** — プロキシ再起動や再ダイヤルなど
- 🌍 **62 言語** — システム言語に自動追従、メニューから切替も可能
- 🪶 **依存ゼロ** — アプリ 1 つだけ。デーモンも Homebrew も不要

## インストール

[Releases](../../releases) から `.dmg` をダウンロードして「アプリケーション」にドラッグするだけです。

初回起動時に「開発元を検証できません」と表示された場合（未署名アプリの通常の挙動）は、**アプリを右クリック → 開く → 開く** を選ぶか、次を実行してください:

```bash
xattr -dr com.apple.quarantine /Applications/LTEGuard.app
```

## 使い方

1. 起動するとメニューバーにアイコンが表示されます
2. メニュー → **対象を選択…** → 使用中のアダプタを選びます（`· USB` 付きはソフト抜き差しに対応）
3. 以上です。以後は閉じて開いても、切れていれば自動で直ります

うまくいかないときはメニューの **診断を実行** をお試しください。
